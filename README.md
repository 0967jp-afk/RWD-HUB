# RWD-Hub: лендинг и демо

Все файлы лежат в одной папке, подпапок нет.

- `index.html` — лендинг
- `demo.html` — кликабельный прототип (кнопка «Демо» открывает его в новой вкладке)
- `shot-*.jpg` — скриншоты интерфейса для лендинга

Публикация: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
Прямые ссылки на роли: `demo.html#clinic`, `demo.html#pharma`, `demo.html#admin`, `demo.html#expert`.
Почта в блоке «Контакты» (сейчас `i@eogawa.ru`) меняется в `index.html`, поиск по `mailto:`.
